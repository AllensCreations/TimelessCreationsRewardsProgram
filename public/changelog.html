v1.4.0 August 27, 2026

🛡️ Security Hardening, Isolated Template Sandbox, & Universal Global Sync

  • SecurityAdmin Authorization Guards: Enforced strict `ADMIN_SECRET` / bearer token validation across all sensitive database mutations and management actions in `api/main.js`.
  • SecurityWebhook HMAC Validation: Wired up cryptographic verification for incoming Meta Messenger payloads using `X-Hub-Signature-256`.
  • FeatureIsolated Iframe Sandbox: Isolated custom monthly HTML email previews in a secure iframe container, completely eliminating CSS stylesheet leakage into dashboard views.
  • FeatureUniversal Global Refresh: Standardized event dispatching across all admin views so that clicking "Global Refresh" instantly re-fetches and re-renders data across all pages.
  • FixSQL Parameter Mismatch: Resolved parameter binding alignment in `save_drip` queries to ensure custom HTML templates and custom subject lines save reliably to Turso.
